# 2026-10-31 메타 및 설명 갱신

## 확인한 패치 근거

[라이엇 18.5 한국어 패치 노트](https://teamfighttactics.leagueoflegends.com/ko-kr/news/game-updates/teamfight-tactics-patch-18-5/)의 10월 28일 추가 변경을 확인했다.

- 카직스의 기본·고립 피해량이 모두 하향됐다.
- 덩굴정령의 방어력 무시 계산이 변경됐다. 주문력 계수가 줄고 기본값이 늘었으므로 모든 빌드에서 동일한 폭의 하향이라고 단정하지 않는다.
- 정의의 손길의 모든 피해 흡혈이 15%에서 12%로, 찬란한 버전은 30%에서 25%로 줄었다.

설명에서는 기존 아이템 예시와 실제 덱 구성을 유지하면서, 회복 아이템 하나만으로 근접 딜러의 생존을 보장하지 않도록 안내한다. 카직스의 접근 경로와 탱커의 첫 피격, 회복 억제 여부를 함께 판단한다. 이는 패치와 배치에 근거한 운영 안내이며, 전투 시뮬레이션이나 아이템 승률 비교 결과가 아니다.

신규 설명은 [공통 템플릿](templates/detail_info.md)을 따른다. 크롤링한 출처 설명은 원문 수집 흐름을 유지하고, 직접 작성한 설명은 `MetaGuide(source='ai', level=0)`과 배포용 설명 파일로 관리한다.

## 로컬 반영 결과

- 롤체지지 39개, OP.GG 50개, tactics.tools 23개 수집 완료.
- 중복·배치·참조 검증 후 신규 메타 14개 저장. 전체 메타 82개에서 96개로 증가.
- 출처 상세 연결 90개, 설명·배치 527개 항목 반영. 이 중 레벨 배치는 484개.
- 신규 작성 설명 14개와 기존 설명 보완 11개 적용. 배포용 작성 설명은 총 62개.
- 전체 96개 응답의 빈 `detail_info` 0개 확인. 신규 메타 769번 POST 검색 성공 및 기존 메타 683번의 5레벨 응답 5유닛 확인.
- 설명 가져오기 재검증 결과 적용 예정 0개, 건너뜀 96개. Django 시스템 검사 통과.

tactics.tools의 배치 미확인 15개는 좌표·성급을 추정하지 않아 신규 저장에서 제외했다. 롤체지지 나무정령 이즈리얼 한 구성은 기초 DB에 깊은숲 수호자가 없어 제외했고, 고밸류 드레이븐의 8레벨 배치도 같은 참조 누락으로 제외됐다. 다른 사이트에서 확인된 별도 이즈리얼 변형은 저장했다. 기존 메타 삭제나 배치 없는 목록의 강제 저장은 하지 않았다.

이번 변경에는 애플리케이션 코드·브라우저 설정·마이그레이션 변경과 새 테스트 파일이 없다. 배포 서버에서의 실행은 [적용 안내](meta-guides-deploy.md)를 따른다.
