# 2026-11-22 메타 및 설명 갱신

기준: 세트 18, 패치 18.7. 통계 사이트의 전체 흐름은 [18.7 조사 기록](tft-research-18.7.md) 7절에 정리했다.

## OP.GG 수집 변경

OP.GG 목록 카드에는 챔피언 이름과 아이템만 있고 위치·별이 없어, 상위권 덱이 "배치 미확인"으로 계속 빠졌다. 각 카드의 덱 상세 페이지(`deckId` 링크)에는 서버가 렌더링한 데이터가 들어 있어 `meta_crawl`이 이를 순서대로 한 번씩 읽는다.

- **대표 배치:** `comp.units`의 실제 별과 장착 아이템을 사용한다. 위치는 같은 페이지의 `guide.positioning.cell`(0부터, 앞줄→뒷줄 순서, 7×4)에 1을 더해 저장한다. 이 위치는 OP.GG가 덱과 무관하게 유닛별 전체 통계로 정해 화면에 표시하는 값이다. 유닛 하나라도 위치가 없으면 그 덱은 저장하지 않는다.
- **대표 레벨:** `comp.level`.
- **레벨 배치:** `guide.timeline.levels`의 레벨별 등장 유닛을 등장률 순으로 레벨 수만큼 고르고, 위치는 위 `positioning`에서 가져온다. 위치가 없는 유닛이 끼면 그 레벨은 저장하지 않는다. 그래서 빠른 8·9 덱은 초반 유닛 위치가 없어 레벨 배치가 거의 없다.
- 상세 데이터의 별은 실제 관측값이므로 1성→2성 보정 대상에서 제외한다. 보정은 별 표시가 없던 이전 화면 구조의 보드에만 적용한다.

## 로컬 반영 결과

- 수집: 롤체지지 36개, OP.GG 43개(43개 모두 배치 확인), tactics.tools 21개.
- 신규 메타 14개 저장(전체 102 → 116). 제목이 같은 다른 덱은 `개화 아리 7`처럼 번호를 붙였다. 배치가 없는 tactics.tools 13개는 저장하지 않았다.
- 상세 설명 연결 55개, 저장 항목 268개(레벨 배치 228개).
- 대표 설명이 비어 있던 14개를 새로 작성했다: 상징별 챔피언 요약 3, 처형자 아지르, 처형자 소라카/자이라, 개화 아리 7, 나무정령 아펠리오스 4, 주문술사 아리 2, 나무정령 이즈리얼 3, 기원자 코그모, 적응가 니달리 2, 전쟁기계 케이틀린, 개화 니달리, 처형자 이즈리얼 2, 검은 가시 아지르, 지옥불 바루스.
- 전쟁기계 자이라는 tactics.tools 설명이 이미 있어 규칙대로 새로 쓰지 않았다. 협곡야수 어미부리 등 롤체지지 설명이 있는 773~777도 유지했다.
- 전체 116개의 `detail_info`가 비어 있지 않다. `import_meta_guides`와 `--update` 재실행 결과 모두 적용 예정 0개.
