## 2. 18.6~18.7 변경 중 설명에 영향을 주는 것

영문 명칭의 한국어 대응은 게임 데이터와 대조해 표기했다. 확실하지 않은 것은 `(추정)`으로 남긴다.

### 특성 소속이 바뀐 유닛 (18.7) — 특성 구간 설명에 직접 영향

- **케넨: 날렵이로 이동**, **아이번: 나무정령으로 이동**. 이전 설명에서 케넨·아이번으로 세던 특성 수가 달라질 수 있으므로, 이 두 유닛이 있는 덱은 현재 DB의 특성 정보로 구간을 다시 센다.
- **돌거북(Kruggs): 소환사 특성 추가**, 소환될 때 체력 15% 증가, 기본 체력은 감소. 현재 상위권인 소환사 어미 부리 덱의 핵심 변경이다.

해석 원칙:

- **순방형과 고점형을 구분한다.** 소환사 어미 부리는 순방률이 높고, 알룬·드레이븐은 승률이 높지만 순방률은 보통이다. 설명의 개요에서 이 성격을 구분하되 수치 자체는 본문에 쓰지 않는다.
- **티어에 따라 순위가 뒤집힌다.** 기원자 티모처럼 플래티넘+에서 좋고 마스터+에서 평범한 덱, 드레이븐·마스터 이처럼 높은 티어에서 더 좋은 덱이 있다. 쉬운 리롤 덱은 낮은 티어 성적이 부풀려질 수 있다.
- **픽률이 매우 낮은 덱(0.05 이하)의 평균 등수는 표본 착시일 수 있다.** 특수 증강·상징 조건이 붙은 경우가 많다.

## 4. 아이템 패턴 (OP.GG 18.7 핵심 유닛 아이템)

- **주력 탱커의 표준 조합:** 가고일 돌갑옷 / 워모그의 갑옷 / 정령의 형상. 대체로 수호자의 맹세(감시자·헤카림·릴리아), 크라운가드(람머스·말파이트), 굳건한 심장(람머스)이 들어간다.
- **공속형 물리 캐리:** 구인수의 격노검 + 크라켄의 분노 / 무한의 대검 / 죽음의 검 (아펠리오스·드레이븐·트리스타나·자야·케이틀린). 케이틀린·어미 부리·아지르·베이가에는 마법공학 총검이 들어가 회복을 보완한다.
- **스킬형 캐리:** 쇼진의 창 또는 푸른 파수꾼 + 보석 건틀릿 + 피해 아이템 (아리·티모·알룬·르블랑·카르마·카시오페아). 아리는 플래+ 기준 타격대의 철퇴 또는 푸른 파수꾼이 함께 나온다.
- **보조 유틸리티 담당:** 최후의 속삭임·붉은 덩굴정령·쇼진의 창은 애쉬·이즈리얼·시비르 같은 보조 딜러가 맡는 경우가 많다. 모렐로노미콘·공허의 지팡이는 모르가나·자이라·르블랑이 맡는다. 설명의 아이템 우선순위에서 "이 기능을 누가 담당하는가"를 쓸 때 이 패턴을 근거로 삼는다.
- **근접 지속 딜러:** 정의의 손길 / 밤의 끝자락 / 스테락의 도전·수은 (아칼리·카직스·덩굴정령·어스름늑대·니달리·카밀).

이 목록은 완성 조합 빈도이지 제작 순서가 아니다(`tft-item-priorities.md` 원칙 유지).

## 6. 다음 detail_info에 적용할 점

1. 케넨·아이번이 있는 덱은 18.7 특성 이동을 반영해 특성 구간을 다시 센다. 이전 설명을 복사하지 않는다.
2. 나무정령 덱은 소환물 체력 하향을 반영해 "소환물이 앞라인을 대신한다"는 표현을 피하고, 실제 탱커 아이템 배분을 먼저 쓴다.
3. 돌거북이 포함된 소환사 덱은 돌거북의 소환사 역할을 확인한다.
4. 개요에서 순방형(안정)과 고점형(1등 노림)을 구분해 진입 판단을 돕는다. 통계 수치와 티어 문자는 본문에 넣지 않는다.
5. 아이템은 4절 패턴을 참고하되, 실제 DB 배치의 아이템을 우선한다.
6. 세트 18의 마지막 패치이므로 다음 세트(19.1, 12월 1일 예정)부터는 이 문서의 덱 평가를 쓰지 않는다.

- **덱 이름 대응 주의:** tactics.tools의 "협곡야수 어미 부리"와 OP.GG의 "소환사 어미 부리", "날렵이 아지르"와 "처형자 아지르"가 같은 덱인지는 확인하지 못했다.
